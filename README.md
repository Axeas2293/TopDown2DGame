# 2D Top-Down Farming Simulator

A private hobby project created out of my interest in game development and programming.
The goal of this project is to build a small 2D top-down farming simulator featuring core gameplay mechanics such as farming, resource management, and progression.

## Project Idea

The player manages their own farm, grows crops, harvests resources, and gradually expands the farm over time.
The focus is on creating simple and enjoyable gameplay while learning and applying technical concepts during development.

## Features (planned / partially implemented)

* 2D top-down game world
* Player movement and controls
* Planting, growing, and harvesting crops
* Inventory / resource system
* Farm upgrades and expansion
* Day / night cycle 
* Seasonchanges 
* Additional gameplay ideas in progress

## Background

This is a private, learning project which is exclusively made for my enjoyment.

## Status

Work in progress / experimental project.
